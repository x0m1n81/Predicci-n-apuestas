# Predicción Apuestas — Motor multicriterio v2

Esta versión parte de la anterior y añade un motor de selección más conservador.

MEJORAS
- Puntuación por varias señales disponibles: predictor, mercado y récord.
- Niveles PREMIUM / FUERTE / MEDIO / NO BET.
- Probabilidad estimada normalizada para comparar ambos equipos.
- Filtro por nivel de pick.
- No inventa predicciones cuando faltan datos.
- Mantiene fútbol, baloncesto, tenis y motor.

IMPORTANTE
Esta versión NO afirma que tenga un winrate garantizado. Las señales proceden de los datos públicos que devuelve ESPN y algunas competiciones pueden no ofrecer predictor, cuotas o récord en el navegador. Para conseguir un consenso real entre varias fuentes (Forebet, StatFooty, etc.) hace falta integrar sus datos mediante fuentes permitidas/APIs o un backend; no se simulan esos datos.
