# Predicción Apuestas

Web app móvil para analizar partidos.

## Archivos
- `index.html`
- `app.js`
- `style.css`
- `manifest.webmanifest`

## GitHub Pages
Sube estos cuatro archivos a la raíz del repositorio y activa GitHub Pages usando la rama `main` y la carpeta `/ (root)`.

La aplicación actual es la base de interfaz. Para picks con datos reales habrá que conectar una fuente/API accesible.
